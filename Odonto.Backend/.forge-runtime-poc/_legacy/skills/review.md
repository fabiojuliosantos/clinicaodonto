# Review Skill

## Goal

Execute a technical review using the supplied context.

---

## Responsibilities

- Analyze the supplied changes.
- Apply the project's engineering philosophy.
- Respect the documented architecture.
- Use the available project context.
- Produce a clear and objective review.

---

## Restrictions

Review only the supplied material.

Do not assume missing files, implementations or business rules.

---

## Output

Follow the deliverables defined by the Review Context.
